五分钟写出第一个界面

这一页只讲最短路径：找到工程、写脚本、运行、看到结果。更细的接口在「常用接口」，导出安装包在「打包与权限」。

界面与入口

启动后先看到品牌启动页，随后进入编辑器。编辑器顶部是菜单，常用项包括新建工程、打开工程、运行、打包、设置。

  • 运行：直接执行当前工程脚本，错误会以独立页面提示，同时写入日志快照。
  • 打包：把当前工程组装成可以安装的成品包，详见「打包与权限」。
  • 设置：主题、编辑器字号、存储目录等开关。

目录都在哪

位置路径用途
外部目录/storage/emulated/0/LuaXPlus工程文件、日志，卸载后仍保留
主程序日志/storage/emulated/0/LuaXPlus/logs运行日志、警告/错误/崩溃快照
成品日志/storage/emulated/0/LuaXPlus/products/包名/logs每个打包成品各自一套日志
私有目录/data/user/0/com.mini.luaxplus/files运行时脚本，首次启动自动铺设
首次安装后，程序会申请「所有文件访问」权限。授权前日志暂存在私有目录，授权后自动切换到外部目录；工程读写同样依赖这项权限。

第一个脚本

新建工程后，把下面内容写进 main.lua，运行时就会看到标题和一个居中文本。

require "import"
import "android.widget.*"
import "android.view.*"
import "autotheme"

activity.setTitle("你好")
activity.setTheme(autotheme())

local layout = LinearLayout(activity)
layout.setOrientation(LinearLayout.VERTICAL)
layout.setGravity(Gravity.CENTER)

local text = TextView(activity)
text.setText("Hello, Mini-LuaXPLUS")
text.setTextSize(20)
layout.addView(text)

activity.setContentView(layout)

脚本里的 activity 是当前页面对象，几乎所有界面操作都从它出发；import 负责引入 Java 类与 Lua 模块。

让它响应点击

给控件挂监听，写法和 Android 原生一致，只是用 Lua 函数代替匿名类：

local button = Button(activity)
button.setText("点我")
button.setOnClickListener(View.OnClickListener{
  onClick = function(v)
    Toast.makeText(activity, "被点了一下", Toast.LENGTH_SHORT).show()
  end
})
layout.addView(button)
监听回调要写成表的形式（{ onClick = function(...) ... end }），Lua 会自动转换成 Java 接口实现。

脚本放在哪、怎么被加载

运行时程序把内置的脚本基础模块铺到私有目录，再执行你工程的 main.lua。因此工程里可以直接 require "import"、import "loadlayout" 等，不需要自己拷贝依赖。

  • 工程内的其它 .lua 文件按相对路径 require 即可。
  • 基础模块位于私有目录的 lua 子目录，模块搜索路径已自动包含。
  • 同名文件以工程内为准，会覆盖内置版本。

出错了看哪里

脚本报错会弹出错误页，同时生成一份快照。文件命名规则：

文件名含义
luaerror_日期_时分秒_毫秒.log脚本运行错误，含错误正文与堆栈
warn_日期_时分秒_毫秒_进程号.log警告快照，同一警告 5 秒内只留首条
crash_日期_时分秒_毫秒_进程号.log程序崩溃，含完整堆栈与设备信息
app_日期.log当天运行日志，含普通信息与警告行
