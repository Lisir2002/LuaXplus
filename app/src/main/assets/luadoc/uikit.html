LuaX-UI 组件库 iOS 风格 · 纯增量

LuaX-UI：iOS 风格原生组件库

一套可直接在 Lua 脚本里使用的 Android 原生组件。它只新增模块，不改变 import、luajava、LuaActivity 或原有的 View 写法。

想看完整工程
打开首页左侧栏的「官方示例」，进入「LuaX-UI 组件库示例」。它是一个独立示例工程，覆盖本页全部组件，可以直接编辑、运行和打包；官方示例与自建工程分开存放，互不影响。
先记住三条规则
1. 组件库是可选的，原有代码一行都不用改；
2. 所有组件最终都是普通 Android View，随时可以和原生 View 混用；
3. 视觉参考 iOS 的系统分组、留白、圆角、细分割线和系统色，不是把 UIKit 搬过来。

一、加载与最小示例

在 Activity 脚本里加载模块，然后创建一个页面。下面的代码可以直接运行：

local ui = require "luaxplus.ui"

local page = ui.page{
  title = "设置",
  subtitle = "账户与偏好",
  back = false,
  largeTitle = true,
}

page:add(ui.group("账户", {
  ui.row{ title = "个人资料", subtitle = "头像、昵称与签名", onClick = function()
    ui.alert{ title = "提示", message = "这里可以打开资料页" }
  end },
  ui.row{ title = "通知", toggle = true, onToggle = function(value)
    print("通知开关:", value)
  end },
}))

page:add(ui.button{
  text = "退出登录",
  style = "destructive",
  onClick = function()
    ui.alert{
      title = "退出登录",
      message = "退出后需要重新登录。",
      actions = {
        { title = "取消", style = "cancel" },
        { title = "退出", style = "destructive", onClick = function()
          print("已退出")
        end },
      },
    }
  end,
})

page:show()
ui.page 会隐藏系统 ActionBar，并按 iOS 的大标题布局排好导航栏、内容滚动区和安全区。页面内容默认是浅灰分组背景，组件卡片是白色圆角块。

二、不影响原生写法

LuaX-UI 没有接管 activity.setContentView，也没有改写全局类。你仍然可以：

-- 原生写法完全保留
local tv = TextView(activity)
tv.setText("原生 TextView")
tv.setTextSize(16)

local page = ui.page{ title = "混用示例" }
page:add(tv)                       -- 直接把原生 View 放进页面
page:add(ui.button{ text = "继续" })

-- 需要完全自己控制时，仍然可以
-- activity.setContentView(root)

也可以拿到页面容器自己安排：

page.content.addView(tv)
page.root.setBackgroundColor(0xFFFFFFFF)
page.nav.setVisibility(View.GONE)

三、页面骨架 page

ui.page(options) 返回一个页面对象，常用字段如下：

字段说明
title导航栏标题；开启大标题时同时作为大标题。
subtitle大标题下方的一行灰色说明。
back是否显示左上角返回按钮；默认调用 activity.finish()。
onBack自定义返回逻辑；设置后不再自动 finish。
right右上角文字按钮，可写字符串或 {title, onClick}。
largeTitle默认 true；设为 false 只保留 44dp 小标题栏。
background / navBackground覆盖页面背景色 / 导航栏底色。

页面对象的方法：

page:add(view, topMargin)        -- 追加一个 View，可带顶部间距
page:addGroup(header, rows, footer)
page:setTitle("新标题")
page:show()                      -- 真正调用 activity.setContentView(root)

四、主题与明暗模式

默认跟随系统深浅色。需要强制某一套时：

ui.setAppearance("light")   -- 浅色
ui.setAppearance("dark")    -- 深色
ui.setAppearance("auto")    -- 跟随系统

local colors = ui.tokens.color
print(colors.accent, colors.bg, colors.label)

自定义主题、完整令牌和 HTML CSS 导出见后面的“设计令牌”章节。

主题在组件创建时读取。已经创建的页面不会自动换色；切换主题后重新创建页面即可。系统状态栏和导航栏颜色会随 ui.page 一起设置。

五、分组列表 group 与 row

iOS 设置页的核心结构：浅灰背景 + 白色圆角分组 + 行内细分割线。

page:add(ui.group("通用", {
  ui.row{ title = "关于本机", value = "1.0.0", chevron = true, onClick = showAbout },
  ui.row{ title = "语言", value = "简体中文", onClick = chooseLanguage },
  ui.row{ title = "深色模式", toggle = true, onToggle = function(on)
    ui.setAppearance(on and "dark" or "light")
  end },
}, "更改语言后部分界面需要重新进入"))

page:add(ui.group("存储", {
  ui.row{ title = "清理缓存", value = "128 MB", onClick = clearCache },
  ui.row{ title = "删除账户", destructive = true, onClick = confirmDelete },
}))

ui.row 支持的字段：

字段说明
title / subtitle主标题与第二行灰色说明。
value右侧灰色值文本，例如版本号、容量。
icon左侧图标；可传一个字符，或直接传 ImageView/View。
iconBg字符图标的底色，默认系统蓝。
chevron是否显示右侧箭头；默认在有点击事件时显示。
toggle / onToggle显示 iOS 风格开关；回调收到当前布尔值。
selected显示蓝色对勾，用于选择类列表。
accessory自定义右侧附件 View，优先级最高。
destructive标题使用系统红，用于删除类操作。
disabled整行降低透明度并禁用。
onClick行点击回调。

十三、完整示例：一个设置页

下面的脚本可以单独运行，包含大标题、分组、开关、输入、分段选择、弹窗和底部按钮：

local ui = require "luaxplus.ui"

local page = ui.page{
  title = "设置",
  subtitle = "账户、通知与外观",
  back = false,
}

local nameField = ui.fieldRow{
  label = "昵称",
  value = "Lua 开发者",
  placeholder = "请输入昵称",
}

page:add(ui.group("账户", {
  ui.row{ title = "头像", value = "未设置", onClick = function()
    ui.alert{ title = "头像", message = "这里可以接入相册或相机。" }
  end },
  nameField,
}, "昵称会显示在个人主页。"))

page:add(ui.group("通知", {
  ui.row{ title = "允许通知", toggle = true },
  ui.row{ title = "声音", toggle = false },
  ui.row{ title = "震动", toggle = true },
}))

local appearance = ui.segmented{
  items = { "跟随系统", "浅色", "深色" },
  selected = 1,
  onChange = function(index)
    if index == 1 then
      ui.setAppearance("auto")
    elseif index == 2 then
      ui.setAppearance("light")
    else
      ui.setAppearance("dark")
    end
    ui.alert{ title = "已切换", message = "重新进入页面后全部组件会使用新配色。" }
  end,
}
page:add(appearance.view)

page:add(ui.button{
  text = "保存设置",
  onClick = function()
    ui.alert{
      title = "已保存",
      message = "昵称：" .. tostring(nameField.input.getText().toString()),
    }
  end,
})

page:show()

十五、快捷页面 show 与表单 form

最常用的两个能力已经收成一行式入口：ui.show 建页面，ui.form 建表单。它们不是新运行时，仍然返回普通 View。

local ui = require "luaxplus.ui"

local form = ui.form{
  title = "账号",
  fields = {
    { name = "nickname", label = "昵称", placeholder = "输入昵称" },
    { name = "email", label = "邮箱", placeholder = "name@example.com", email = true },
  },
  footer = "ui.form 返回 getValues()、setValues() 和 reset()。",
}

ui.show{
  title = "快速上手",
  subtitle = "一个页面、一个表单",
  content = function(_, page)
    page:add(form.view)
    page:add(ui.button{
      text = "保存",
      onClick = function()
        ui.toast("昵称：" .. form.getValues().nickname)
      end,
    }, 12)
  end,
}
接口作用
ui.show(spec)创建页面、执行 content 回调、显示并播放入场动画；spec.animate=false 可关闭。
ui.form(spec)用 fieldRow 快速生成一组字段，返回 view、inputs、getValues()、setValues()、reset()。
page:reveal()对页面内容做错峰入场；可传 { step, duration, preset }。

十六、更多高效组件

这些组件都返回普通 View 或 { view, ... } 表，可以单独用，也可以组合进 group 和 card。

page:add(slider.view)

local stepper = ui.stepper{ label = "数量", value = 2, min = 0, max = 20 }
page:add(stepper.view)

})

page:add(ui.statRow{
  { value = "20+", label = "组件" },
  { value = "260ms", label = "动画" },
  { value = "0", label = "额外依赖" },

组件说明
chip / chipGroup胶囊标签和单选 chip 组；chipGroup 返回 view、getSelected、setSelected。

slider带标签和数值的 SeekBar，返回 view、getValue、setValue。

banner轻量提示条，支持图标、标题、说明和 action。

fab圆形悬浮按钮，支持 onClick。
toast自定义圆角 Toast，支持 text、long、offset。

十七、动画：animate、stagger、press

动画是纯增量封装，不改变 View 本身。默认使用 260ms 的减速曲线，支持上移、下移、缩放和纯淡入。

local ui = require "luaxplus.ui"

ui.animate(view, { preset = "up", duration = 260 })
ui.animate(view, { preset = "scale", delay = 80 })
ui.stagger({ first, second, third }, { step = 50, preset = "up" })
ui.press(button, { scale = 0.97 })
page:reveal({ step = 45, duration = 280 })
接口预设
ui.animate(view, spec)up、down、fade、scale；可设 duration、delay。
ui.stagger(views, spec)给一组 View 按顺序错峰播放，step 默认 55ms。
ui.press(view, spec)按下缩放、抬起回弹；不拦截原有点击事件。
page:reveal(spec)对页面直接子 View 做错峰入场，适合页面首次显示。
动画只改变 alpha、translation 和 scale，不改变布局尺寸；如果页面需要实时重绘，先完成数据更新，再播放动画。

十八、和原生代码混用的建议

场景推荐做法
普通设置页、表单、弹窗直接用 LuaX-UI，保持视觉统一。
需要自定义绘制、复杂动画在 Kotlin/Java 里写自定义 View，再用 page:add(view) 放进来。
超长数据列表继续使用原生 RecyclerView 或 LuaAdapter，不要把所有行都塞进 ScrollView。
已有页面逐步迁移保留原布局，只把按钮、分组、弹窗替换成组件；不需要一次性重写。

十九、打包与发布

组件库放在 assets/lua/luaxplus/ui.lua，会随基础模块铺设到运行时的 app_lua，所有成品包会自动带上，不需要在工程里复制文件，也不需要改打包脚本。

iOS 风格开关是一个很小的原生 View（com.mini.luaxplus.ui.IosSwitch），已经随模板 APK 一起打包；Lua 侧通过 luajava 反射创建，不依赖额外权限。

成品包使用时同样写 local ui = require "luaxplus.ui"。如果某个工程不想用组件库，不 require 即可，原有代码和包体积都不受影响。

二十、设计令牌：默认主题与自定义主题

组件库的颜色、间距、圆角、字体、控件尺寸、动效和透明度都来自 ui.tokens。组件创建时读取令牌，所以换主题后重建页面即可整体换肤。

同一套令牌既支持“档位选择”，也支持“数值填入”：spacing.page、radius.button、textSize = "body" 是档位；spacing = "18px"、radius = 14、textSize = "15px" 是无级数值。所有颜色同时接受整数和 #RRGGBB：

local t = ui.tokens

t.color.accent
t.color.label
t.color.surface
t.spacing[16]
t.spacing.page
t.radius[12]
t.radius.button
t.type.body.size
t.type.caption.tracking
t.control.buttonHeight
t.control.avatar
t.opacity.scrim
t.motion.slow
分类用途
color背景、表面、文字、分隔线、强调色、成功/警告/危险、遮罩、透明色和禁用色。
spacing页面、卡片、行、间距和图标尺寸的 dp 数值，数字键可直接访问；另有 label/helper/checkbox/tab/kv/motion 语义别名。
radius卡片、按钮、输入框、标签和胶囊圆角。
typedisplay/title/body/callout/footnote 等字号、字重和行高。
control导航、按钮、输入框、标签栏、悬浮按钮、头像、步进器和弹窗动作高度。
motion / opacity / elevation动效时长、错峰间隔、透明度刻度、按压缩放和阴影高度。

数值无级调节

所有需要尺寸、字号、圆角、透明度的字段都走同一个解析器；原子组件的文本字重、字距、内边距、输入框最小高度、表面高程和透明底色也都从令牌读取。除了数字，还可以写带单位的字符串："10px"、"12dp"、"15sp"、"18pt"，以及透明度百分比 "35%"。没有单位的字符串按数字处理。

ui.button({
  text = "保存",
  textSize = "15px",      -- 字号
  radius = "14px",        -- 圆角
})

ui.background({
  src = "hero.jpg",
  height = "190px",
  radius = 18,
  contentPadding = "20px",
}, content)

ui.withAlpha(ui.tokens.color.accent, "35%")   -- 透明度
ui.withAlpha("#000000", 140)                  -- 0-255 也可以
字段类型可用写法说明
尺寸/间距/高度数字、"12px"、"12dp"、"page"、"card"后缀按 Android 的逻辑尺寸处理，最终换算为 dp。
字号数字、"15px"、"15sp"、"body"、"caption"最终写入 SP；字号令牌名仍然优先。
圆角数字、"14px"、"button"、"card"语义圆角可统一改主题。
透明度0-1、0-255、"35%"、"scrim"百分比会换算成 0-1，再写入 alpha。
动效时长数字、"200ms"、"slow"毫秒数值。

常用的语义圆角可以直接写名称，不必记数字：

radius.card      = 12
radius.button    = 12
radius.input     = 12
radius.chip      = 16
radius.sheet     = 14
radius.nav       = 22
radius.avatar    = 20
radius.fab       = 26

需要自己算尺寸时，可以复用组件库的解析器：

ui.dp("12px")       -- 转成 Android 像素
ui.number("35%")    -- 0.35
ui.metric("12dp")   -- 12

注册自定义主题。顶层字段同时覆盖浅色和深色，dark 只写深色差异：

ui.defineTheme("brand", {
  extends = "light",
  color = {
    accent = "#FF6B00",
    accentSoft = "#FFF0E6",
  },
  spacing = { page = "20px", [16] = 20 },
  radius = { button = "14px", [12] = 14 },
  type = { body = { size = "18px" } },
  dark = {
    color = {
      accent = "#FF9F45",
      accentSoft = "#3A2110",
    },
  },
})

ui.useTheme("brand")          -- 跟随系统深浅色
ui.useTheme("brand", "dark")  -- 强制深色
ui.useTheme("auto")           -- 回到默认主题

按字符串读取令牌，适合根据变量拼路径：

ui.token("color.accent")
ui.token("spacing.16")
ui.token("type.body.size", 17)

导出 CSS 变量，给 HTML/H5 或设计文档复用同一套令牌：

print(ui.cssVars("brand"))
print(ui.cssVars("brand", "dark"))
:root {
  --lx-color-accent: #FF6B00;
  --lx-spacing-page: 20px;
  --lx-radius-button: 14px;
  --lx-type-body-size: 18px;
}
令牌在创建 View 时读取，不是响应式绑定。切换主题或自定义主题后，重建当前页面；不要在旧页面上期待自动换色。

二十一、透明度、图片与背景

透明度、图片和背景都复用同一套令牌，不额外引入图片库。透明度既可以传 0-1 的小数、0-255 的整数、"35%" 百分比，也可以直接传 ui.tokens.opacity 里的名称。

令牌值典型用途
transparent0完全透明
faint0.04极轻的提示层
subtle0.08轻量底色、选中态
light0.12浅遮罩、弱化背景
medium0.24图片蒙层、次要信息
strong0.48强调遮罩
heavy0.72深色蒙层、文字压图
solid0.96接近不透明
disabled0.42禁用控件
pressed0.7按压缩放层
overlay0.35弹窗遮罩
scrim0.55图片上的文字保护层
shimmerLow0.28骨架屏循环的低透明度
shimmerHigh0.72骨架屏循环的高透明度
 
local veil = ui.withAlpha("#000000", 0.35)
local soft = ui.withAlpha(ui.tokens.color.accent, "light")   -- 也可以用令牌名
local alpha = ui.withAlpha(ui.tokens.color.onAccent, "strong")

ui.withAlpha 只改颜色的 alpha，不改变 RGB，适合做半透明底、遮罩、状态色和文字压图。

图片组件

ui.image 返回普通 ImageView，可以直接放进任何布局。支持本地路径、HTTP 路径、Bitmap、Drawable 和 Android 资源 id。

-- 本地图片；相对路径会自动拼到 Lua 目录，没有扩展名时补 .png
local cover = ui.image({
  src = activity.getLuaExtDir("examples/luax-ui-demo") .. "/hero.jpg",
  scale = "cover",     -- cover / contain / fill / center / inside
  radius = 12,         -- 圆角，可传 radius 令牌键
  alpha = "90%",
  tint = ui.tokens.color.accent,
})
page:add(cover, 12)

-- 圆形头像
local avatar = ui.image({
  src = "avatar.png",
  circle = true,
})
avatar.setLayoutParams(LinearLayout.LayoutParams(dp(56), dp(56)))
page:add(avatar)
字段类型说明
srcstring / Bitmap / Drawable / number图片源；path、image 是同义别名。
scalestringcover（默认，裁切铺满）、contain、fill、center、inside。
radiusnumber / string圆角半径，传数字 dp 或 radius 令牌键。
circleboolean圆形裁切；优先于 radius。
alphanumber / string0-1、0-255 或透明度令牌名。
tintcolor颜色滤镜，适合单色图标。
width / heightnumber最小尺寸；精确尺寸请用 LayoutParams。
placeholdercolor图片为空或加载失败时的底色。
adjustboolean是否按图片比例调整 View 边界，默认 true。

背景卡片

ui.background 在图片上叠加遮罩，再放内容，适合头图、登录页、专题卡和活动入口。内容可以是 View，也可以是函数。

local hero = ui.background({
  src = "hero.jpg",
  height = "190px",
  radius = "18px",
  scale = "cover",
  overlay = ui.withAlpha("#000000", "medium"),
}, function(box)
  local title = TextView(activity)
  title.setText("背景图片")
  title.setTextSize(ui.tokens.type.title.size)
  title.setTextColor(ui.tokens.color.onAccent)
  box.addView(title)

  local note = TextView(activity)
  note.setText("图片铺底 + 遮罩 + 内容层")
  note.setTextColor(ui.withAlpha(ui.tokens.color.onAccent, 0.82))
  box.addView(note)
end)
page:add(hero, 14)
字段说明
src / scale / alpha与 ui.image 相同，图片自动铺满。
height最小高度，单位 dp 数值。
radius圆角；图片和内容层一起裁切。
overlay遮罩颜色；传 false 关闭遮罩。默认 palette.scrim。
background没有图片时的底色，或图片加载前的占位色。
contentPadding内容内边距，默认 16，数字键走 spacing 令牌。
gravity内容对齐，默认 Gravity.CENTER_VERTICAL。

整页背景

ui.page 新增页面级背景参数；page.frame 是最外层容器，page.root 仍是内容主体，原有 page.root.addView(...) 不受影响。

local page = ui.page({
  title = "首页",
  backgroundImage = "hero.jpg",
  backgroundScale = "cover",
  backgroundOverlay = ui.withAlpha("#000000", "scrim"),
  backgroundAlpha = 0.92,
})
字段说明
backgroundImage整页背景图；不传时仍用 background 或 palette.bg。
backgroundScale默认 cover。
backgroundOverlay整页遮罩颜色；传 false 关闭。
backgroundAlpha背景图透明度，0-1、0-255 或令牌名。
图片加载是同步的：本地文件很快；HTTP 图片会阻塞 UI 线程。网络图建议先在后台线程下载并缓存到本地，再传给 ui.image。大图先按目标尺寸缩放，避免把原图直接塞进小卡片。

二十二、选择、数据与折叠组件

新增一组高频但之前缺失的组件：开关、单选组、评分、下拉选择、键值列表、表格、时间线、折叠容器、头像组和分页器。它们全部复用现有颜色、间距、圆角、字体、控件和透明度令牌，没有引入新的视觉体系。

组件用途核心字段

二十三、原子组件：把每一类拆到最小

原子组件的视觉值全部收口到令牌：spacing.labelX/labelY、spacing.helperX/helperTop、spacing.checkboxX/checkboxY/checkboxGap、spacing.tabTop/tabBottom/tabGap、spacing.kvX/kvY、spacing.motionY，透明底色使用 color.transparent。

复合组件解决“一个完整场景”，原子组件解决“一个最小视觉单元”。新增的原子层覆盖布局、排版、图标、表单、选择、反馈、导航、数据和动效，复杂页面可以按需组合，不必被现成组件的参数限制。

分类原子组件作用
布局surface、stack/vstack/hstack、grid、center底色容器、行列栈、网格和居中容器。
排版text、label、helper统一字号、字重、颜色、对齐、行数和帮助文本。
图标icon（glyph / src / glyphSize）、statusDot字形或图片图标，以及成功/警告/危险状态点。
表单input、label、helper裸输入框、字段标签和错误/帮助文本。
选择checkMark、checkbox、radioMark、switch勾选、单选、开关的最小可交互单元。
导航tabItem底部标签栏的单个标签项；支持字形或 src 资源图标。
数据cell、kvRow表格单元格和键值行。
动效fadeIn、slideIn、scaleIn淡入、上移、缩放的短入口。

布局、排版与图标

local panel = ui.surface({
  padding = "16px",
  radius = "14px",
}, function(body)
  body.addView(ui.hstack({ gap = "8px", align = "center" }, function(add)
    add(ui.icon({
      glyph = "A",
      size = "30px",
      background = ui.tokens.color.accent,
      color = ui.tokens.color.onAccent,
    }))
    add(ui.text({ text = "标题", type = "headline" }))
    add(ui.statusDot({ color = ui.tokens.color.success }))
  end))
end)

page:add(panel)

page:add(ui.grid({
  columns = 3,
  gap = "8px",
  items = { tileA, tileB, tileC, tileD },
}))

page:add(ui.center({ padding = 24 }, ui.text("居中内容")))

stack 的 add() 会自动加 gap；grid 最后一行会自动留白；icon 既支持字形，也支持 src 图片。

表单与选择

page:add(ui.label({ text = "项目名", required = true }))
page:add(ui.input({
  hint = "输入项目名",

page:add(ui.checkbox({
  text = "自动保存",
  checked = true,

}))

  add(ui.radioMark({ checked = true }))

二十四、限制与常见问题

  • 这是 iOS 风格的 Android 组件，不是 UIKit。 系统字体、阴影和动画与真机 iOS 仍有差异。
  • 主题切换不会实时重绘已有控件。 切换后重建页面即可。
  • 不要在一个 ScrollView 里嵌套长列表。 数据量大时用原生 RecyclerView / LuaAdapter。
  • 组件只封装常用能力。 需要新组件时，可以继续在 assets/lua/luaxplus/ui.lua 里追加，不影响已有调用。
  • 原生写法永远可用。 组件库只是可选的语法糖，不是新的运行时。
