常用接口速查

按使用频次排列：先搞清 import 与 luajava，再看界面、数据、网络，最后是权限和日志。

import 与模块

require 找 Lua 模块，import 既能引入 Lua 模块，也能把 Java 包的类变成可用名字。

require "import"          -- 引入 import 机制本身
import "android.widget.*" -- 引入一整个 Java 包
import "loadlayout"       -- 引入内置 Lua 模块
import "http"
  • 模块搜索路径已包含工程目录、私有目录 lua 与 app_lua，普通模块直接写名字即可。
  • 工程内文件与内置模块重名时，工程内优先。
  • 模块名里的点按目录层级解析，例如 require "luaxplus.log" 对应 luaxplus/log.lua。

luajava：直接调用 Java

三类最常用操作：取类、建对象、实现接口。

local Intent = luajava.bindClass("android.content.Intent")
local intent = Intent(activity, activity.getClass())
activity.startActivity(intent)

-- 实现接口（表转 Java 接口对象）
local runnable = luajava.newInstance("java.lang.Runnable", {
  run = function()
    print("在子线程里执行")
  end
})
local Thread = luajava.bindClass("java.lang.Thread")
Thread(runnable).start()

布局与控件

两种写法：代码直接搭，或用表描述交给 loadlayout 生成。

require "import"
import "android.widget.*"
import "android.view.*"
import "loadlayout"

local layout = {
  LinearLayout,
  orientation = "vertical",
  padding = "16dp",
  {
    TextView,
    id = "title",
    text = "标题",
    textSize = "20sp",
    textColor = "#1C2B3A",
  },
  {
    Button,
    id = "ok",
    text = "确定",
  },
}

activity.setContentView(loadlayout(layout))
title.setText("已加载布局")
表里第一个元素是控件类，字符串键对应 setter 方法（text 对应 setText），子表是子控件。

对话框与菜单

import "android.app.*"
AlertDialog.Builder(activity)
  .setTitle("提示")

  .setPositiveButton("知道了", nil)

网页与编辑器

  • LuaWebView(activity)：内置浏览器控件，支持加载本地页面与网址，本手册就是用它展示的。
  • LuaEditor(activity)：带行号、语法高亮的代码编辑控件，主界面编辑器基于它。
  • LuaUtil：LuaUtil.copyFile(源, 目标)、读取文本等工具方法。

文件与路径

local path = activity.getLuaDir()              -- 当前工程所在目录
local ext = activity.getLuaExtDir()            -- 外部存储根目录（LuaXPlus）
local f = io.open(path .. "/data.txt", "w")
f:write("内容")
f:close()

LuaUtil.copyFile(path .. "/a.txt", ext .. "/b.txt")
方法返回
activity.getLuaDir()当前脚本所在目录
activity.getLuaExtDir()外部存储下的程序目录
activity.getLuaPath("名称")拼接出当前目录下的完整路径

网络请求

require "http"

local body = {}
local code, headers, status = http.request{
  url = "https://www.example.com/",
  method = "GET",
  headers = {
    ["User-Agent"] = "Mini-LuaXPLUS",
  },
  sink = ltn12.sink.table(body),
}
  • http.request 返回状态码、响应头与状态行，响应正文按 sink 收集。
  • 需要长连接或自定义协议时用 require "socket"。
  • 另有 ftp、smtp 模块，分别处理文件传输与发信。

数据格式

require "json"
local text = encode({ name = "豆包", tags = { "lua", "android" } })
local obj = decode(text)

require "base64"
local encoded = encode("原始内容")
local raw = decode(encoded)

require "hex"
local h = encode("AB")      -- 十六进制
local raw2 = decode(h)

require "xml"
local doc = xml.new()       -- 构造与遍历 XML
local node = xml.tag(doc, "root")
json 与 base64、hex 引入后直接提供全局 encode / decode，同时使用时注意先后覆盖，建议显式写成模块调用或分开作用域。

线程与定时任务

import "android.os.Handler"
import "android.os.Looper"

local main = Handler(Looper.getMainLooper())
local task = luajava.newInstance("java.lang.Runnable", {
  run = function()
    -- 回到界面线程刷新控件
  end
})

main.postDelayed(task, 1000)   -- 1 秒后执行一次
main.post(task)                -- 立即投递到界面线程

耗时任务放到子线程执行，结果通过主线程 Handler 回投，避免界面卡顿或跨线程改控件。

权限

成品包已内置完整权限清单，脚本只需要在用到时申请一次：

import "permissions"

permissions.ensure("storage")            -- 所有文件访问，会打开系统授权页
permissions.ensure("camera", "microphone")
permissions.ensure("location", "contacts")

if permissions.granted("camera") then
  -- 已授权
end

可用的简写：storage、read_storage、write_storage、 camera、microphone、contacts、calendar、 location、phone、sms、notification、 overlay，也可以直接写完整权限名。

日志

内置日志模块会把内容写进与崩溃快照同一套目录，排查时非常有用：

local log = require "luaxplus.log"

log.i("业务", "流程开始")
log.w("业务", "参数为空，使用默认值")   -- 会额外生成警告快照
log.e("业务", "请求失败: " .. tostring(err))

print(log.dir())   -- 当前日志目录

直接用 Java 侧接口也可以：luajava.bindClass("com.mini.luaxplus.LogCore").i("标签", "内容")。

调试技巧

  • 用 print 或 log.i 观察执行顺序，日志里带毫秒时间戳。
  • 报错后先看 luaerror_*.log 的堆栈第一条，通常直接指出脚本与行号。
  • 界面白屏但没有报错时，检查是否在子线程里改了控件。
