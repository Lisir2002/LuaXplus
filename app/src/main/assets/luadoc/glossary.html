术语表 概念对照

名词对照与通俗解释

手册和日志里出现的名词，这里给出工程语境下的含义，避免和 Lua 语言术语混淆。

工程与目录

名词含义
工程目录一个应用的脚本与资源所在目录，打包时以它为输入
私有目录系统分配给应用的内部空间，卸载即清空；运行时脚本铺在这里
外部目录/storage/emulated/0/LuaXPlus，工程与日志所在，卸载后保留
app_lua私有目录下给脚本用的模块目录，脚本的模块搜索路径包含它
入口脚本main.lua，运行或打包时的起点

运行时

名词含义
铺设首次启动把安装包内的脚本与模块复制到私有目录的动作
dex安卓可执行的字节码文件；打包组件也用 dex 形式随包分发
activity当前页面对象，脚本里的界面操作入口
luajava脚本调用 Java 类的桥梁，可取类、建对象、实现接口
签名给安装包打上身份标记；系统据此判断能否覆盖安装
归档对齐安装包内部条目的存放规则，资源表需不压缩且四字节对齐

日志与排错

名词含义
运行日志app_日期.log，当天所有记录按时间顺序
快照单个错误或崩溃独立成文件，含时间、版本、线程、堆栈
警告快照warn_*.log，非致命问题也留证据
堆栈错误发生时的调用链，第一条通常指向真正出错的位置
成品包由工程打包出的独立安装包，日志单独一套目录
